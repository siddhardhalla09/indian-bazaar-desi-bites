# Indian Bazaar & Desi Bites Website

This folder is ready for GitHub Pages.

## Upload To GitHub

1. Go to GitHub and create a new repository.
2. Name it something like `indian-bazaar-desi-bites`.
3. Choose **Public**.
4. Click **Create repository**.
5. Click **uploading an existing file**.
6. Drag these files and folder into GitHub:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `.nojekyll`
   - `assets`
7. Click **Commit changes**.
8. Go to **Settings**.
9. Go to **Pages**.
10. Under **Build and deployment**, choose:
    - Source: **Deploy from a branch**
    - Branch: **main**
    - Folder: **/root**
11. Click **Save**.

GitHub will publish the site after a minute or two. The link will appear on the Pages settings screen.

## Edit Before Publishing For Real Customers

Replace these placeholder values:

- Phone display: `(555) 123-4567`
- Phone digits: `15551234567`
- Email: `orders@indianbazaar.example`
- Address: `123 Market Street, Your City, ST 00000`
- Hours: `10:00 AM - 9:00 PM`

The phone and email appear in both `index.html` and `script.js`.

## What This Site Does

- Shows Indian Bazaar grocery categories
- Shows Desi Bites restaurant menu items
- Lets customers create grocery, restaurant, or catering pickup requests
- Lets customers copy, email, or WhatsApp the request
- Does not collect online payment
